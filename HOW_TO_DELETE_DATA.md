# Как удалить данные из Supabase

## ⚠️ ВНИМАНИЕ

Удаление данных необратимо! Убедитесь, что у вас есть резервная копия, если данные могут понадобиться.

## Способы удаления

### 1. Удалить ВСЕ данные (все темы, подразделы, разделы)

```bash
npm run delete-all-data
```

**Что будет удалено:**
- Все темы (topics)
- Все подразделы (subsections)
- Все разделы (sections)

**Безопасность:** Скрипт запросит подтверждение. Нужно ввести "ДА" для продолжения.

### 2. Удалить конкретную тему

```bash
npm run delete-topic -- --id=m1
```

**Примеры:**
```bash
# Удалить тему m1
npm run delete-topic -- --id=m1

# Удалить тему m2
npm run delete-topic -- --id=m2
```

### 3. Удалить через Supabase Dashboard (вручную)

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **Table Editor**
4. Выберите таблицу (`topics`, `subsections`, или `sections`)
5. Выберите строки для удаления
6. Нажмите **Delete** или используйте кнопку удаления

### 4. Удалить через SQL (в Supabase SQL Editor)

#### Удалить все темы:
```sql
DELETE FROM topics;
```

#### Удалить все подразделы:
```sql
DELETE FROM subsections;
```

#### Удалить все разделы:
```sql
DELETE FROM sections;
```

#### Удалить конкретную тему:
```sql
DELETE FROM topics WHERE id = 'm1';
```

#### Удалить все данные (каскадное удаление):
```sql
-- Сначала темы (зависимости)
DELETE FROM topics;

-- Затем подразделы
DELETE FROM subsections;

-- Затем разделы
DELETE FROM sections;
```

## Рекомендации

1. **Сделайте резервную копию** перед удалением:
   - Экспортируйте данные через Supabase Dashboard
   - Или используйте SQL: `SELECT * FROM topics;` и сохраните результат

2. **Проверьте зависимости:**
   - При удалении раздела удалятся все связанные подразделы и темы (каскадное удаление)
   - При удалении подраздела удалятся все связанные темы

3. **Используйте транзакции** для безопасности:
   ```sql
   BEGIN;
   DELETE FROM topics WHERE id = 'm1';
   -- Проверьте результат
   -- Если все ОК:
   COMMIT;
   -- Если нужно отменить:
   ROLLBACK;
   ```

## Восстановление данных

Если вы случайно удалили данные:

1. **Из резервной копии:**
   - Восстановите из экспортированного файла
   - Или используйте скрипт `npm run upload-data` для повторной загрузки

2. **Из локальных файлов:**
   - Все данные хранятся в `src/data/allTopics.ts`
   - Запустите `npm run upload-data` для повторной загрузки

## Отключение Supabase

Если вы хотите полностью отключить Supabase и использовать только локальные данные:

1. В файле `.env` установите:
   ```env
   VITE_USE_SUPABASE=false
   ```

2. Или удалите/закомментируйте:
   ```env
   # VITE_SUPABASE_URL=...
   # VITE_SUPABASE_ANON_KEY=...
   ```

3. Приложение автоматически переключится на локальные данные из `src/data/allTopics.ts`
