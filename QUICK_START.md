# Быстрый старт: Добавление материалов в Supabase

## 🎯 Самый простой способ

### Шаг 1: Создайте таблицы в Supabase

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **SQL Editor** (левое меню)
4. Откройте файл `supabase-schema.sql` из проекта
5. Скопируйте весь SQL код
6. Вставьте в SQL Editor и нажмите **Run** (или F5)

✅ Готово! Таблицы созданы.

### Шаг 2: Загрузите данные автоматически

```bash
npm run upload-data
```

Скрипт автоматически загрузит:
- ✅ 5 разделов (Механика, Термодинамика, Электричество, Оптика, Атомная физика)
- ✅ Все подразделы (Кинематика, Динамика, и т.д.)
- ✅ Все 86 тем с полным контентом

### Шаг 3: Проверьте результат

1. Перезапустите dev-сервер: `npm run dev`
2. Откройте раздел "Библиотека"
3. Убедитесь, что все темы отображаются

## 📝 Добавление одной темы вручную

### Через Supabase Dashboard:

1. **Table Editor** → выберите таблицу **topics**
2. Нажмите **Insert** → **Insert row**
3. Заполните поля:

```
id: m1
title: Прямолинейное движение
description: Движение тела по прямой линии
theory: [Вставьте полный текст теории]
formulas: ["v = s/t", "x = x₀ + vt"]
examples: ["Пример 1", "Пример 2"]
problems: ["Задача 1", "Задача 2"]
section_id: mechanics
subsection_id: kinematics
order_index: 1
```

**Важно:** Поля `formulas`, `examples`, `problems` должны быть JSON массивами:
- ✅ Правильно: `["Формула 1", "Формула 2"]`
- ❌ Неправильно: `Формула 1, Формула 2`

### Через SQL:

```sql
INSERT INTO topics (
  id, title, description, theory, formulas, examples, problems,
  section_id, subsection_id, order_index
)
VALUES (
  'm1',
  'Прямолинейное движение',
  'Движение тела по прямой линии',
  'Полный теоретический материал...',
  '["v = s/t", "x = x₀ + vt"]'::jsonb,
  '["Пример 1"]'::jsonb,
  '["Задача 1"]'::jsonb,
  'mechanics',
  'kinematics',
  1
);
```

## 🔍 Проверка данных

После загрузки проверьте:

```sql
-- Посмотреть все темы
SELECT id, title, section_id FROM topics ORDER BY section_id, order_index;

-- Подсчитать темы по разделам
SELECT section_id, COUNT(*) as count FROM topics GROUP BY section_id;
```

## ❓ Проблемы?

Если скрипт не работает:
1. Проверьте, что `.env` файл создан и содержит правильные ключи
2. Убедитесь, что таблицы созданы (выполнен SQL скрипт)
3. Проверьте консоль на наличие ошибок
