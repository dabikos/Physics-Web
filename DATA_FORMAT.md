# Формат данных для загрузки в Supabase

## 📋 Как отправить материал

Вы можете отправить материал в любом из следующих форматов:

### Вариант 1: Прямо в чат
Просто вставьте данные в сообщение, и я создам скрипт для загрузки.

### Вариант 2: JSON файл
Создайте файл `src/data/topicsData.json` и заполните его по образцу ниже.

### Вариант 3: Структурированный текст
Отправьте данные в любом удобном формате, я адаптирую.

## 📝 Формат JSON файла

```json
{
  "sections": [
    {
      "id": "mechanics",
      "title": "Механика",
      "description": "Движение, силы, энергия, импульс",
      "icon_name": "Gauge",
      "color": "from-blue-500 to-cyan-500",
      "total_topics": 22,
      "order_index": 1
    }
  ],
  "subsections": [
    {
      "id": "kinematics",
      "title": "Кинематика",
      "section_id": "mechanics",
      "order_index": 1
    }
  ],
  "topics": [
    {
      "id": "m1",
      "title": "Прямолинейное движение",
      "description": "Движение тела по прямой линии",
      "theory": "Полный теоретический материал здесь...",
      "formulas": ["v = s/t", "x = x₀ + vt", "v = v₀ + at"],
      "examples": [
        "Автомобиль движется со скоростью 60 км/ч. За 2 часа он проедет: s = 60 × 2 = 120 км",
        "Тело начинает движение с ускорением 2 м/с². Через 5 секунд его скорость: v = 0 + 2 × 5 = 10 м/с"
      ],
      "problems": [
        "Автомобиль разгоняется с 0 до 100 км/ч за 10 секунд. Найдите ускорение.",
        "Поезд движется со скоростью 72 км/ч. Какой путь он пройдет за 30 минут?"
      ],
      "section_id": "mechanics",
      "subsection_id": "kinematics",
      "order_index": 1
    }
  ]
}
```

## 🔑 Обязательные поля

### Для разделов (sections):
- `id` - уникальный идентификатор (mechanics, thermodynamics, etc.)
- `title` - название
- `description` - описание
- `order_index` - порядок сортировки

### Для подразделов (subsections):
- `id` - уникальный идентификатор
- `title` - название
- `section_id` - ID раздела
- `order_index` - порядок сортировки

### Для тем (topics):
- `id` - уникальный идентификатор (m1, m2, t1, e1, etc.)
- `title` - название темы
- `description` - краткое описание
- `section_id` - ID раздела
- `subsection_id` - ID подраздела
- `order_index` - порядок сортировки
- `theory` - полный теоретический материал (опционально)
- `formulas` - массив формул (опционально)
- `examples` - массив примеров (опционально)
- `problems` - массив задач (опционально)

## 📤 После подготовки данных

1. **Если используете JSON файл:**
   ```bash
   npm run upload-json
   ```

2. **Если отправили данные в чат:**
   Я создам скрипт специально для ваших данных

3. **Если используете автоматический скрипт:**
   ```bash
   npm run upload-data
   ```
   (загрузит все данные из локальных файлов)

## 💡 Примеры форматов

### Простой текст:
```
Раздел: Механика
Подраздел: Кинематика
Тема: Прямолинейное движение

Теория:
[ваш текст теории]

Формулы:
- v = s/t
- x = x₀ + vt

Примеры:
- Пример 1
- Пример 2
```

### Табличный формат:
```
ID | Название | Описание | Теория
m1 | Прямолинейное движение | Движение по прямой | [текст]
```

Любой формат подойдет - я адаптирую под нужную структуру!
