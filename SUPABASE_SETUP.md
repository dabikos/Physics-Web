# Настройка Supabase для Physics AI Dashboard

## Шаг 1: Создание проекта в Supabase

1. Перейдите на [supabase.com](https://supabase.com)
2. Создайте новый проект
3. Запишите URL проекта и Anon Key из настроек проекта

## Шаг 2: Создание таблиц в базе данных

1. В Supabase Dashboard перейдите в раздел **SQL Editor**
2. Откройте файл `supabase-schema.sql` из корня проекта
3. Скопируйте весь SQL код и выполните его в SQL Editor
4. Убедитесь, что все таблицы созданы успешно

## Шаг 3: Настройка переменных окружения

1. Создайте файл `.env` в корне проекта (если его нет)
2. Добавьте следующие переменные:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

3. Замените значения на ваши реальные данные из Supabase Dashboard

## Шаг 4: Загрузка данных

После создания таблиц вам нужно загрузить данные о темах. Вы можете:

### Вариант 1: Использовать SQL скрипты
Создайте SQL скрипты для вставки данных из ваших локальных файлов

### Вариант 2: Использовать админ-панель Supabase
Загрузите данные через веб-интерфейс Supabase

### Вариант 3: Создать скрипт миграции
Используйте утилиты из `src/lib/supabaseTopics.ts` для загрузки данных

## Шаг 5: Проверка подключения

1. Запустите проект: `npm run dev`
2. Откройте консоль браузера
3. Проверьте, что нет ошибок подключения к Supabase
4. Перейдите в раздел "Библиотека" и убедитесь, что данные загружаются

## Структура базы данных

### Таблица `sections`
- `id` - уникальный идентификатор раздела (mechanics, thermodynamics, etc.)
- `title` - название раздела
- `description` - описание
- `icon_name` - название иконки
- `color` - цвет градиента
- `total_topics` - общее количество тем
- `order_index` - порядок сортировки

### Таблица `subsections`
- `id` - уникальный идентификатор подраздела
- `title` - название подраздела
- `section_id` - ссылка на раздел
- `order_index` - порядок сортировки

### Таблица `topics`
- `id` - уникальный идентификатор темы
- `title` - название темы
- `description` - описание
- `theory` - теоретический материал (текст)
- `formulas` - массив формул (JSON)
- `examples` - массив примеров (JSON)
- `problems` - массив задач (JSON)
- `section_id` - ссылка на раздел
- `subsection_id` - ссылка на подраздел
- `order_index` - порядок сортировки

## Безопасность

По умолчанию настроены политики Row Level Security (RLS):
- Чтение данных разрешено всем (публичный доступ)
- Запись можно настроить для аутентифицированных пользователей

## Полезные команды

```sql
-- Посмотреть все разделы
SELECT * FROM sections ORDER BY order_index;

-- Посмотреть все темы раздела
SELECT * FROM topics WHERE section_id = 'mechanics' ORDER BY order_index;

-- Обновить количество тем в разделе
UPDATE sections 
SET total_topics = (
  SELECT COUNT(*) FROM topics WHERE section_id = 'mechanics'
)
WHERE id = 'mechanics';
```
